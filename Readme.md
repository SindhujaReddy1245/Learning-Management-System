# LearnFlow LMS

An Learning Management System designed for modern students and educators.  
This platform helps users learn smarter with interactive courses, quizzes, AI assistance, automatic notes generation, and progress tracking.

---

## 🚀 Features

### 👨‍🎓 User Features
- User Authentication (Login / Signup)
- Browse Courses & Modules
- Attend Quizzes
- AI Tutor Assistant
- Auto Notes Generation
- Track Learning Progress
- Responsive Dashboard

### 🛠️ Admin Features
- Manage Users
- Add/Edit/Delete Courses
- Create Modules & Quizzes
- Monitor Student Progress
- Analytics Dashboard

---

## 🧠 AI Features
- AI Tutor Chat Assistant
- Automatic Notes Generation
- Smart Learning Support
- Personalized Learning Experience

---

## 🛠️ Tech Stack

### Frontend

### Backend

### Database
